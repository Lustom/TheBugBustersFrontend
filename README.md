# TheBugBusters (Frontend)

*This repository contains the **Frontend** source code for TheBugBusters project, developed for the Dedalus Datathon 2025. The backend logic, including the chatbot engine and the database, can be found in the [Backend Repository](https://github.com/Lustom/TheBugBustersBackend).*

The main challenge of the event consisted of providing medical staff with a user-friendly tool featuring a professional chatbot capable of retrieving critical patient information, such as names, ages, and current medical treatments.

To address this, a simple yet effective UI was developed, designed to ensure intuitive navigation for non-technical users. On the left side of the screen, a list of assigned patients is displayed alongside an automated tool used to instantly generate up-to-date PDFs containing essential medical records. On the right side, the chat interface is located. This chat session is completely isolated for each patient, ensuring the conversation remains entirely focused on the correct individual. Standard UI features, such as a dark mode, were also implemented. 

The frontend interface was built using HTML, CSS, and JavaScript.
